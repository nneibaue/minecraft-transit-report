**As a** developer on this mod, **I want to** launch a real Minecraft 1.20.1 dev client that has my mod loaded in it, **so that** every later phase has a place to actually see its work run.

> **Provenance:** this story is planner-derived from the ROADMAP Phase 1 goal, not lifted from it. The
> ROADMAP `**Goal:**` line for this phase ("The development loop is proven end to end…") is written as
> an outcome, not in `As a / I want to / so that` form. Run `/gsd mvp-phase 01` if you want the canonical
> user story written back into the ROADMAP; nothing in this plan depends on that happening.

This plan is the phase tracer: the thinnest path that touches every layer the runtime side of Phase 1 has — the mod manifest, the mixin configs, the Java entrypoint, Fabric Loader, and a live game window — wired end to end and proven by artifacts the run itself produced.

That unknown is the single largest risk in the phase, so it is answered first, on the smallest possible change set.

Output: a mod that names itself honestly, carries no inert template mixins, and has been observed running in a live 1.20.1 dev client with a reusable Creative Superflat dev world saved for Phase 2 onward.

## Flagged assumptions (edge-probe unresolved — surfaced, not dropped)

The deterministic edge probe was run over this phase's requirements because no SPEC.md exists. It
returned `TOOL-01` as **`unclassified` / `unresolved`**: the probe's shape taxonomy (boundaries,
adjacency, encoding, ordering) has no category for a requirement whose subject is a build task and a
game window rather than a data shape. Per protocol an `unclassified` row is never auto-resolved and
never auto-dismissed, so it is surfaced here as an explicit assumption rather than silently absorbed
into `must_haves`.

- **TOOL-01 — edge dimensions not enumerated by any probe.** What remains un-enumerated is the set of
  *partial-success* states of a game launch: the client that reaches the title screen but fails on world
  load; the client that loads but silently swallows a mod-init exception; the launch that succeeds on a
  JDK other than the one the docs will claim. This plan addresses those three by hand — `run/options.txt`
  for title-screen reach, `run/saves/gsd-dev/level.dat` for world load, the absence of `run/crash-reports`
