## Planner reconciliation: marked devices skip the GitHub update

Taken literally, D-16 ("startup.lua re-downloads chat.lua and client.lua on every boot") and D-14 ("uv run deploy becomes the author's optional no-push dev shortcut", with D-04's reload step being `reboot`) contradict each other. A developer runs deploy, then reboots, and the reboot immediately overwrites the deployed Lua with whatever `main` holds.

The smallest change that keeps both true: `startup.lua` skips the download when `_marker.txt` exists. D-14 already scopes that marker to the deploy dev path, so marked devices are exactly the deploy-managed ones.

- Devices set up with `install.lua` never have a marker, so they auto-update as D-16 requires.
- A developer returns a device to GitHub updates by deleting `_marker.txt`.

<reversibility rating="reversible">Removing the skip is a three-line deletion in startup.lua plus one test. No device data or wire protocol depends on it.</reversibility>

The operator can veto this at review. If they do, delete the skip, and the README's developer shortcut must then say "push before rebooting".

- CC:Tweaked 1.116.1 API facts, verified against tweaked.cc and the mc-1.20.x wget.lua source on 2026-09-25:
  - `http.get` accepts a table `{url, headers, binary, method, redirect, timeout}`. It returns a response handle, or `nil, err, failResponse`; a non-2xx status counts as a failure (since 1.80pr1).
  - Handle methods: `getResponseCode()`, `readAll()`, `close()`.
  - fs API paths are absolute from the computer root whatever `shell.dir()` says.
  - `fs.open` modes include `"rb"` and `"wb"`. Since 1.109.0 text mode also uses raw bytes; binary modes are used here anyway so the behaviour does not depend on the version.
  - `read(replaceChar, history, completeFn, default)`: `read("*")` masks the typed input, and the 4th argument pre-fills the prompt (1.80pr1).
  - `wget run <url>` loads the body with `load(res, name, "t", _ENV)` and pcalls it, so the installer runs in the shell's environment and is never saved to disk. wget itself saves with `fs.open(path, "wb")`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub raw CDN -> device | Every boot, a device executes Lua it downloaded from raw.githubusercontent.com. Bodies can be stale, truncated, or an error page |
| Admin keyboard -> install.lua | The token and the bridge URL are typed in game by a non-technical admin |
| install.lua -> an arbitrary computer | Anyone at a computer's prompt can run the wget line, including on the author's other turtles |
