## Flagged Assumptions (spec-less edge probe, SRV-01/SRV-03 "concurrency")

- **SRV-01 concurrency:** No atomicity or locking is implemented for `computercraft-server.toml`
  writes; if the deploy process were killed mid-write, the file could be left partially written. This is
  accepted for a single-operator, single-PC local tool with no concurrent invocation expected -- not
  tested or mitigated in Phase 3.
- **SRV-03 concurrency:** No file-locking is implemented for concurrent `deploy` invocations against the
  same marked folder; a single operator running one `deploy` at a time is assumed, matching the
  project's single-PC, single-operator scope.
