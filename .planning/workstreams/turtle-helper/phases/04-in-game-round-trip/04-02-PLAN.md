## How this plan runs

The live steps belong to the author and the operator: the bridge terminal, the server, and every keypress in game. No agent starts a process or acts in game (live-run rule). Checkpoint text uses "the base computer (the one with the Chat Box)". If the author asks why there are two computers, the answer is one line: the base computer is the mouth (the Chat Box) and the second computer, added in Plan 04-03, is the hands; there are two because CC:Tweaked routes websocket events by URL.

Task 3's fix loop is run inline by the orchestrator (D-08). It edits, checks, commits, pushes and runs RAW_MATCH itself; no executor is spawned per fix. A continuation executor does Tasks 2 and 5 and the SUMMARY.

Reading device A's debug log (read-only, prints no secret):
`cd turtle/turtle-helper && uv run python -c "from bridge.settings import Settings; p = Settings().server_dir / 'world/computercraft/computer/0/debug.log'; print(p.read_text(encoding='utf-8', errors='replace')[-4000:])"`
