This entry can be retired from STATE.md's Blockers/Concerns.

## Recipe Category: JSON Field vs. Advancement Path

The generated recipe JSON's `"category": "misc"` field is **not** direct proof of which `RecipeCategory` enum constant the builder was given — it is the coarser crafting-book category the builder maps onto, and several distinct source categories can collapse to the same JSON value. The **advancement's file path** (`advancements/recipes/misc/transit_chart.json`) is the stronger, discriminating evidence, because that folder segment is derived directly from the recipe category passed to `RecipeCategory.MISC` at the call site. A later reader auditing which category this recipe uses should check the advancement path, not the recipe JSON's `category` field.
