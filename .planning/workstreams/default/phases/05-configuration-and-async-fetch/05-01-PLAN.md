<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Player-editable config file -> `TransitConfig` | `transit-config.json` sits on local disk under `FabricLoader`'s config dir; anyone with local filesystem write access can edit it, and its parsed content directly drives an outbound HTTP request |
| `TransitApiClient` -> external Human Design API (network) | Outbound HTTPS GET to a URL sourced from local config; the response bytes returned to the mod are untrusted network input until validated |
| Async executor thread -> Minecraft main/render thread | `TransitApiClient`'s callback result crosses a thread boundary; anything touching game/render state must marshal via `Minecraft.getInstance().execute(...)` before use |
