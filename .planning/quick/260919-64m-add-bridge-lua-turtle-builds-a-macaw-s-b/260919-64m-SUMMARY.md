### 3. Manual trace (plan's required checks, done regardless of syntax-check result)

- **Heading ring (`out -> right -> back -> left -> out`) applied consistently by
  `turnR`/`turnL`:** `RING_INDEX = { out=1, right=2, back=3, left=4 }`;
  `turnR()` sets `heading = RING[(RING_INDEX[heading] % 4) + 1]` (advances forward through the
  ring); `turnL()` sets `heading = RING[((RING_INDEX[heading] - 2) % 4) + 1]` (advances
  backward). Hand-checked all 4 starting headings against both functions -- each produces the
  expected next/previous ring member.
- **Probe's ring diff maps 0/1/2/3 to out/right/back/left using the same clockwise ring:**
  `recoverHeading()` computes `diff = (COMPASS[probedFacing] - COMPASS[state.fOut]) % 4` over
  `{ north=0, east=1, south=2, west=3 }` (clockwise, matching `turtle.turnRight()`), then
  `HEADING_BY_DIFF = { [0]="out", [1]="right", [2]="back", [3]="left" }` -- exact literal match
  to the plan's specified mapping.
- **The 9-step biome/marker sequence returns to the same cell and `"out"` heading without
  touching `dist`/`lane`:** `checkBiomeMarker()` only calls `turnR`/`turnL` (which mutate
  `state.heading` but never `dist`/`lane`) and `rawStep()`/`stepUp()`/`stepDown()` (which have
  no state side effects at all -- confirmed by reading their bodies, they only call raw
  `turtle.*` primitives and `sleep`). Every code path (success, "couldn't reach marker side",
  "out of marker blocks", "out of signs") ends by calling `backFromMarker()` (the inverse of
  the initial turn), so heading is always restored to `"out"`; position is restored because
  every outward raw step (`rawStep()` at step 2, or step 2+7's pair) is matched by exactly one
  return step, and `stepUp()`/`stepDown()` are likewise paired.
- **`MAX_LENGTH`/no-pieces/fuel/Q checks run only between columns, never mid-column:** all
  four checks live at the top of `mainLoop()`'s `while true do` body, before
  `buildColumn(state.dist)` is called; nothing inside `buildColumn`, `placeColumnPiece`, or
  `checkBiomeMarker` reads `stopRequested`, `MAX_LENGTH`, or fuel.
- **`digDown`/`digUp` appear only in the REPLACE_TERRAIN branch and the probe's cleanup
  `digUp`:** confirmed by grep -- `digDown()` appears exactly once, inside
  `placeColumnPiece`'s `if not placeable and REPLACE_TERRAIN then` branch; `digUp()` appears
  exactly once, inside `recoverHeading()`'s probe cleanup (`if placed then ... turtle.digUp()
  end`). No other call site of either exists in the file.

## Orchestrator review (post-execution)

Read the whole script after the executor returned. One real bug and several hardening
points, fixed in commit `40559e9`:

- **Detour ended facing home.** `checkBiomeMarker` turned around with `turnR(); turnR()` and
  then called the *opposite*-hand turn to "face out", which on the ring lands on `back`. The
  next `forward()` would have walked the turtle home, placing nothing. Now uses
  `faceRel("out")`, which is heading-tracked and correct in every branch.
- Detour now moves with `forward()` and a `state.raised` flag (saved around the sign hop), so
  a reboot mid-sign is recovered: slide back over the main line, drop down, face out.
  `recoverHeading` handles negative lanes (MARKER_SIDE = "left") too.
- An existing sign beside a column is adopted rather than duplicated after `bridge reset`.
- Marker and sign `placeDown()` results are checked; `lastBiome` only advances once a sign
  actually stands on a marker.
- Low plants, kelp, seagrass and snow layers count as open at deck level.
- WIDTH == 1 no longer performs two empty turns per column.
- The resume probe clears an unprotected block above itself once before giving up.
- Marker blocks are no longer "protected" from obstacle clearing (they are never in the
  turtle's path, and protecting cobblestone by name would block natural cobblestone).
