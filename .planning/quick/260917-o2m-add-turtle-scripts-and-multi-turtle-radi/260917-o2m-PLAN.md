=== SPECIFICATION (implement all of it) ===

Purpose: a single, self-contained CC: Tweaked (MC 1.20.1, ATM9, Forge) mining-turtle program.
Loaded with `wget <raw url> startup.lua`; must resume from saved state when run as `startup`
after a reboot. No modem, no GPS.

Setup contract (document at top of file):
- Central chest (Sophisticated Storage; treat as generic inventory peripheral). Turtles
  deposit everything into it and may pull coal (fuel) and lanterns (lights) from it.
- Each turtle sits directly adjacent to one side of the chest, facing AWAY from it. That
  defines its territory. Up to four turtles, one per side.
- Slots: 1 = lanterns, 2 = fuel (coal/charcoal), 3 = junk blocks reserve (cobble / cobbled
  deepslate) for sealing and floors, 4–16 = cargo.
- Config constants at top: LIGHT_SPACING (8), FUEL_MARGIN, MIN_LANTERNS (top-up target),
  STATE_FILE, JUNK_RESERVE (~64), CHEST_RETRY_SECONDS (30), TURTLE_WAIT_SECONDS.

Territory — four wedges tiling an expanding square:
- Local frame: chest at (0,0); home cell (1,0); +x = facing direction away from the chest;
  +z = the turtle's right. Heading 0..3 (0 = +x, 1 = +z, 2 = -x, 3 = -z), tracked in state.
- The turtle owns cells with x >= 1 and -(x-1) <= z <= x. Ring r is the strip x = r,
  z ∈ [-(r-1), r] (length 2r). Four rotated copies tile the square ring exactly (comment
  this with a small ASCII diagram).
- Sweep ring by ring, serpentine: ring r sweeps z ascending, ring r+1 descending, etc.
  At the end of a strip, step outward to x = r+1 at the same z and continue. No fixed
  ring limit; runs until it can't continue (fuel with nothing available) or is stopped.
- Room is 2 tall; the turtle never changes y (except the momentary up/down for a LAVA sign).
  Per cell: classify feet block ahead → dig if junk → move in → classify head block
  (inspectUp) → dig if junk → floor/hazard checks → light check → mark CLEAR → save state.

Only dig junk — the whitelist (data tables at top; extendable):
- JUNK tags: minecraft:base_stone_overworld, forge:cobblestone, forge:stone, minecraft:dirt,
  forge:gravel, forge:sand, forge:sandstone. JUNK name fragments: tuff, calcite,
  dripstone_block, deepslate, cobblestone, andesite, diorite, granite, smooth_basalt.
- ALLOWED ORE tags: forge:ores/coal, forge:ores/copper, forge:ores/iron → dig.
- Any other block with tag forge:ores, or name containing "_ore" → KEEP.
- Everything else (chest, torch, lantern, sign, rail, unknown mod block, bedrock) → KEEP.
- Name containing "turtle" → another turtle: wait TURTLE_WAIT_SECONDS and retry
  indefinitely; never dig, never record as KEEP.
- Fluids: name containing "lava" → LAVA; "water" → WATER (hazards, see below).
- Classification function returns one of: "air", "junk", "keep", "turtle", "lava", "water".
  Use `data.tags` (table keyed by tag name) and `data.name`.

Map and state:
- `map["x,z"]` ∈ CLEAR / KEEP / (unset = unknown). Sealed lava/water cells are KEEP.
- State = { x, z, heading, ring, dir (+1/-1), z_next (next strip z to visit), map, stats }.
  Save with textutils.serialize to STATE_FILE after every cell, after every turn at home,
  and after hazard seals. On start: if STATE_FILE exists → load and resume; else fresh
  state at (1,0), heading 0, ring 1.
- `quarry reset` (args[1] == "reset") deletes STATE_FILE and starts fresh.
- Movement primitives update x/z/heading only on success (check turtle.forward() return).
  Turning helpers: face(h) turning the short way.

Navigation:
- Strip traversal: for the current ring, iterate z from one end to the other. For the next
  target cell: if it's adjacent and its feet block is junk/air → step in (dig if needed).
  If its feet block is KEEP → mark KEEP, skip to the next z. If the target is not adjacent
  (because cells were skipped), BFS over CLEAR cells (4-neighbour) restricted to the wedge
  ∪ {home (1,0)} from the current cell to any CLEAR cell adjacent to the target, walk that
  path, then step into the target. If no such path → mark the target unreachable (KEEP) and
  continue. After the last z of the strip, advance: ring += 1, dir = -dir, target
  (ring, current z) is the first cell of the new strip (it is in range since the new strip
  covers z ∈ [-(ring-1), ring] ⊇ previous range).
- BFS is also used for going home (target (1,0)) and returning to the saved work cell.
  Path length from BFS drives the fuel reserve check.
- Arriving home: face heading 2 (toward the chest at (0,0)); `turtle.inspect()` must
  return a block whose name contains "chest"; otherwise print a clear error including the
  block name seen and `error()` out — do not wander.

Lights (deterministic grid, sunken lanterns):
- Turtles cannot read light. Since MC 1.18 hostiles spawn only at block light 0; a lantern
  emits 15 and light falls 1 per block, so a lantern every LIGHT_SPACING=8 keeps the whole
  room ≥ 7. Comment this.
- In a cell where x % LIGHT_SPACING == 0 and z % LIGHT_SPACING == 0 (use ((z % S) + S) % S
  for negative z): if inspectDown is junk → digDown, select slot 1, placeDown. If the floor
  is not junk (existing light, ore, anything else) → do nothing. If slot 1 is empty →
  set a flag "needLanterns" (go home at next opportunity), keep mining.

Hazards (checked when a cell is entered, and ahead before stepping):
- Lava ahead at feet level: place a junk block into it (slot 3, else any cargo slot holding
  a junk-classified item by name), mark cell KEEP, then if any inventory slot holds an item
  whose name contains "sign": move up (head space is clear), if the head-level block ahead is
  junk dig it, select the sign, `turtle.place("LAVA")`, move back down. If no sign, just seal.
- Lava above (inspectUp): seal with placeUp. Lava below: placeDown a junk block.
- Water: seal the same ways, no sign.
- Missing floor (inspectDown returns false / air): placeDown a junk block. Leave everything
  above head height alone.
- Falling gravel/sand: dig in a loop with sleep(0.3) until the space is clear; bail out
  after ~20 tries and treat as KEEP.

Fuel and cargo:
- refuelIfNeeded(): while fuel < reserve, consume coal/charcoal from slot 2, then from any
  cargo slot (name contains "coal" or "charcoal"); prefer mined coal by refuelling from
  cargo first, then slot 2.
- Reserve = BFS path length home + FUEL_MARGIN. Before each cell, if fuel < reserve after
  refuelling attempts → go home.
- Go home when: all cargo slots 4–16 occupied; needLanterns flag and a light cell is coming
  up (or simply needLanterns); fuel rule.
- At home, facing the chest: top slot 3 up to JUNK_RESERVE from cargo junk first; then drop
  every cargo slot 4–16. If drop fails for a non-empty slot (chest full) → print, sleep
  CHEST_RETRY_SECONDS, retry until it succeeds.
- Top-up from chest: `local chest = peripheral.wrap("front")`; if chest and chest.list then
  scan list() for coal/charcoal and lanterns. `turtle.suck()` only pulls from the first
  occupied slot, so pull up to 13 stacks into empty cargo slots: after each suck, inspect the
  new stack with getItemDetail; if lantern → transferTo slot 1 (up to 64); if coal → refuel
  from it until fuel ≥ reserve*2, then transferTo slot 2; stop when both wants are satisfied
  (lanterns ≥ MIN_LANTERNS and fuel comfortable / slot 2 non-empty) or 13 pulls done. Then
  drop everything else back. Print a hint: "Tip: lock coal and lanterns into the chest's
  first slots so top-ups are instant." If the peripheral is unavailable, fall back to the
  same suck loop without the pre-scan.
- If after top-up fuel is still below what's needed to reach the work cell and back →
  print "Out of fuel and none in the chest. Stopping at home." and stop (do not error out
  with a stack trace).
- After servicing, BFS back to the saved work cell and continue the sweep.

Output: short progress lines only — ring start ("Ring 5 (10 cells)"), going home + reason,
lights placed, hazards sealed, top-up results. No per-move spam.
